# HMAC-SHA256 Aláírt Token Motor (Java 17)

- **Szint:** Medior
- **Fájl:** `Main.java` (Java 17, külső függőség nélkül)

## SaaS kontextus és cél
Base64url + `HmacSHA256` stateless hitelesítési token generálás és lejárati idő ellenőrzés.

## Fordítás és futtatás
```bash
javac Main.java && java Main
```
