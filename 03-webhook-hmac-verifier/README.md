# Webhook HMAC-SHA256 aláíró és ellenőrző

- **Szint:** Junior+
- **Fájl:** `Main.java` (Java 17, külső függőség nélkül)

## SaaS kontextus és cél
Webhook payloadok kriptográfiai aláírása (`javax.crypto.Mac`) és időablakos replay-védelem.

## Fordítás és futtatás
```bash
javac Main.java && java Main
```
